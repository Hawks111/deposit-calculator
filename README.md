# Калькулятор вклада

Одностраничное приложение для расчёта вклада с ежемесячной капитализацией процентов. Форма на React отправляет параметры в Spring Boot API и показывает итоговую сумму и доход.

## Возможности

- Ввод суммы вклада, срока в месяцах и годовой ставки.
- Проверка диапазонов на клиенте и сервере.
- Расчёт с помощью `BigDecimal` и округление результата до копеек.
- Отображение результата и сообщения об ошибке под формой.

## Стек и структура

Java 17, Spring Boot, Maven, React, TypeScript, Vite.

```text
src/main/java/ru/example/deposit/
  controller/   HTTP-запрос и ответ
  dto/          данные запроса и ответа, ограничения полей
  service/      формула расчёта
  exception/    ответы при ошибках ввода
src/test/       тесты расчёта
frontend/src/   форма и стили
src/main/resources/static/   собранный интерфейс
```
